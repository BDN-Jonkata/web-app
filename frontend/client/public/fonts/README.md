# Local interface fonts

Golos Text (Cyrillic and Latin, variable weights) and IBM Plex Mono (regular
and semibold) are reused from the embedded font assets in the supplied reference:
`example/ВЕИ България — симулация.html`.

The interface loads these WOFF2 files locally; it does not request fonts from
Google Fonts. Golos Text is the primary typeface, including Bulgarian text.
IBM Plex Mono is used for numerical values.
